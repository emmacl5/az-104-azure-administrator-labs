# AZ-104 Azure Administrator Labs

This repository documents my hands-on learning journey while preparing for the **Microsoft Certified: Azure Administrator Associate — AZ-104** exam.

The goal of this repository is to demonstrate practical Azure administration skills through guided labs, personal experiments, command-line exercises, troubleshooting notes, and infrastructure deployments.

## Objectives

Through these labs, I am developing practical experience with:

* Microsoft Entra ID identities and access management
* Azure subscriptions and governance
* Azure Storage
* Azure virtual machines and compute resources
* Azure virtual networking
* Azure Monitor and alerts
* Backup and disaster recovery
* Azure CLI and Azure PowerShell
* ARM templates and Bicep
* Infrastructure as Code with Terraform
