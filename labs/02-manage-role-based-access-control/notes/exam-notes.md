# AZ-104 Exam Notes - RBAC

## Built-in Roles

- Owner
- Contributor
- Reader
- User Access Administrator

## RBAC Components

- Security Principal
- Role Definition
- Scope

## Scope Hierarchy

Management Group
↓
Subscription
↓
Resource Group
↓
Resource

## Important Facts

- Azure RBAC controls authorization.
- Microsoft Entra ID performs authentication.
- Owner can assign roles.
- Contributor cannot assign roles.
- Reader has read-only access.
